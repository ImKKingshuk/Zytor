# Changelog

All notable changes to Zytor will be documented in this file.

## Release Types

Zytor uses two release channels:

- **Stable** — Recommended for most users. Fully tested features and improvements.  
  *(Example: `v1.0.0`)*
- **Beta** — Early access to experimental features. May contain bugs, UI changes, or unfinished modules.  
  *(Example: `v1.5.0-beta`)*
